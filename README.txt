GÒ CAO — bản mẫu đọc sách

Đã có:
- Trang Gò Cao theo mẫu hình đã thống nhất.
- Sách "Phía sau bức tường" dùng EPUB Final.
- Nút ĐỌC SÁCH mở khu vực đọc.
- Mục lục lấy trực tiếp từ EPUB.
- Tăng/giảm cỡ chữ.
- Tiến/lùi.
- Nút nhảy 10 trang.
- Khung sẵn cho NGHE SÁCH.

Cách chạy thử:
1. Giải nén thư mục.
2. Vì trình duyệt thường chặn EPUB khi mở file trực tiếp, hãy chạy một web server nhỏ trong thư mục này.
   Ví dụ với Python: python -m http.server 8000
3. Mở: http://localhost:8000

Khi đưa lên Internet, chỉ cần upload nguyên thư mục này lên một dịch vụ hosting tĩnh.
